# The Knowledge Project · 决策备忘录方法说明

## 适用问题

- 重要选择
- 决策
- 选项比较

## 核心原则

- 先定义目标再比较选项
- 把不可逆后果单独列出

## 标准步骤

1. 写清目标、期限和约束
2. 补充保持现状这一选项
3. 比较证据、代价、可逆性与不确定性
4. 写出选择理由和复审触发条件

## 应交付的结果

- 决策备忘录
- 选项比较
- 复审条件
