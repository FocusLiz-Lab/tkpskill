# The Knowledge Project · 决策复盘方法说明

## 适用问题

- 复盘
- 后悔
- 判断失误

## 核心原则

- 不以单次好坏结果评价所有过程
- 只使用当时可获得的信息

## 标准步骤

1. 还原当时记录
2. 分开可控行为与外部事件
3. 比较预测和实际
4. 提出一条可检验的改进规则

## 应交付的结果

- 过程与结果复盘
- 偏差记录
- 改进规则

这是一份工作流手册，不是专家原文。涉及具体事实、引文和案例时，必须回到原子库或原始资料核对。
