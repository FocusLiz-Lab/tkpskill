# The Knowledge Project · 访谈决策案例方法说明

## 适用问题

- 访谈案例
- 嘉宾
- 案例拆解

## 核心原则

- 嘉宾经验不等于主持人主张
- 特殊背景必须保留

## 标准步骤

1. 确认嘉宾和来源
2. 提取情境、选项与推理链
3. 寻找结果和遗漏条件
4. 比较用户情境并说明不能迁移之处

## 应交付的结果

- 案例卡
- 决策链
- 迁移与限制
