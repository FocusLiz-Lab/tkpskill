# The Knowledge Project · 判断与盲区检查方法说明

## 适用问题

- 偏差
- 盲区
- 假设检查

## 核心原则

- 先寻找可推翻自己的信息
- 不同解释需比较证据强弱

## 标准步骤

1. 列出核心结论与依赖假设
2. 检查激励、信息来源和反例
3. 构造最有力的替代解释
4. 安排最能区分解释的验证

## 应交付的结果

- 假设清单
- 反方解释
- 证据缺口与验证
